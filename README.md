# Punyaslok Dutta — workflow portfolio

Live site: **https://punyaslokdutta.github.io/**

A dependency-free, responsive portfolio focused on product judgment, multi-agent development, customer feedback, and a deliberately small GTM loop.

The supporting rationale and source links are in [`research-notes.md`](./research-notes.md). The ready-to-record storyboard is in [`sales-video-script.md`](./sales-video-script.md).

## Preview

From this folder, run any local static server. For example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
